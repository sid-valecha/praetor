1. [Handoff.md](./Handoff.md) — current state, decisions, next concrete action
2. [roadmap.md](./roadmap.md) — design spec
3. [plan.md](./plan.md) — phased execution plan
4. [design-notes.md](./design-notes.md) — locked design decisions, failure modes pre-decided, consultation outputs (skim for any phase you're about to implement)

In public clones, those living docs may be absent or intentionally private. Use [README](./README.md), [CONTRIBUTING](./CONTRIBUTING.md), and [SECURITY](./SECURITY.md) as the public source of truth.

For external contributors and users:

- [README](./README.md) is the public usage boundary, including trust boundaries and adapter requirements.
- [CONTRIBUTING](./CONTRIBUTING.md) is the expected contribution workflow.
- [SECURITY](./SECURITY.md) documents local state sensitivity and known trust boundaries.
